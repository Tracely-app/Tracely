# checkset.json: the /api/check reasoning test set

55 labelled sentences in 5 student-style essays (history, science, health,
economics, literature; 11 sentences each), used by the model eval
(`FINDINGS.md`, `harness/`). This file is the audited artifact: it was
generated by a builder and then label-audited (the `audit` field records the
changes), and neither script is in the repo — edit the JSON directly and keep
the rules below.

## Why it matches production input exactly

- Each `essay.text` is `title + "\n" + one line per paragraph`, which is the shape
  `getDocText()` / `readField()` hand to the extension.
- The text was re-segmented with the extension's own
  `segmentText()`/`hashText()` (content.js on main @2f2ca33), and the
  *checkable* segments are exactly the labelled sentences, in order, with the
  hashes stored here: 0 mismatches. The title line has 6 words or fewer and no
  end punctuation, so it is skipped the same way it is in production.
- No sentence contains an internal `.` `!` or `?`. That means no "et al.",
  "U.S.", "a.m." or decimals, because `segmentText` would split on them. This
  is why the citations read "(Tan and Tatsumura, 2015)" and not "et al.".
- Request per essay, exactly as content.js builds it:
  `{ text: essay.text, sentences: essay.sentences.map(s => ({ id: s.hash, text: s.text })), model, effort }`.
  One essay fits in one batch: 11 sentences, below the extension's limit of 40
  (`MAX_SENTENCES_PER_CHECK`). Every essay is under 1,400 characters, so
  `runFactCheck` never trims the context (it only trims above 6000).
- The system prompt contains today's date. None of the claims depends on
  anything after 2021.

## Vocabulary mapping (labels to FINDINGS_SCHEMA verdicts)

The check can return 6 verdicts: `accurate`, `needs_citation`, `false`,
`questionable`, `incoherent`, `no_claim`. The extension underlines `false`,
`questionable`, `incoherent` and `needs_citation` (`ISSUE_VERDICTS`). It shows
nothing for `accurate` or `no_claim`. That gives `flag_of_verdict`: false→false,
needs_citation→needs_citation, questionable→questionable,
incoherent→incoherent, accurate→none, no_claim→none.

| label (n) | expected.verdict / flag | acceptable (1 pt) | partial (0.5 pt) | critical |
|---|---|---|---|---|
| `false` (12) | false / false | false | questionable | accurate, needs_citation, no_claim |
| `true_uncited` (12) | needs_citation / needs_citation | needs_citation (+accurate on 1 lenient item, e4s05) | accurate | false |
| `cited` (10) | accurate / none | accurate | none | needs_citation, false |
| `common_knowledge` (8) | accurate / none | accurate | no_claim | false |
| `opinion` (8) | no_claim / none | no_claim | accurate | false |
| `trap` (5) | needs_citation / needs_citation | needs_citation, accurate | none | false |

Any verdict that is not in acceptable, partial or critical counts as **wrong**.
Examples: `questionable` on a true statistic or an opinion, or
`needs_citation` on common knowledge. A **missing** finding for an id also
counts as wrong, and should be reported separately.

The **critical** column holds the errors that hurt a student:
- endorsing a falsehood. Note that `needs_citation` on a false sentence
  counts, because it tells the student the claim is right and only needs a
  source.
- calling a true statement false.
- asking an already-cited sentence for a citation. `server/lib/llm.js`
  (the DEFAULT_EFFORT comment) records this false positive for `minimal`
  effort.

Report critical errors per config next to the score.

## Composition

- **false: 12.** By difficulty: 8 subtle, 2 moderate, 2 plain.
  - Subtle: Laika on "Sputnik 1"; Glenn as first American in space; sunlight
    taking "eight seconds"; Salk's vaccine given on a sugar cube; Fleming in
    "1938" behind a real citation; FDR signing Smoot-Hawley; Victor studying
    at "Geneva"; the Animal Farm line attributed to 1984.
  - Moderate: methane weaker than CO2; bond prices rising with rates.
  - Plain controls: Aldrin first on the Moon; antibiotics treating the flu.
  - Every false item has a `correct_fact`.
  - e3s09 is false *and* cited. It tests the prompt's precedence rule, which
    says a wrong claim is `false` even when it carries a citation.
- **true_uncited: 12.** Specific statistics and dated facts with no source.
- **cited: 10.** Four use a parenthetical `(Author, year)`. Six use prose
  attribution ("According to NASA/the CDC/the BLS", "the IPCC stated",
  "Shelley explained", "Orwell said").
- **common_knowledge: 8.**
- **opinion: 8.** Hedged or normative sentences.
- **trap: 5.** Every trap has a `why_true`.
  - 3 surprising but true: the V-2 reached space in 1944; Zimbabwe issued a
    Z$100 trillion note; Shelley was 18.
  - 2 dated but correct for their date: CO2 was about 315 ppm in 1958; the
    leading causes of death in 1900.

## Suggested per-config report

- Accuracy (sum of points divided by 55).
- Critical-error count.
- Recall on false items: all 12, and the 8 subtle ones on their own.
- Precision on `false`: the share of `false` verdicts that land on `false` items.
- Share of cited sentences flagged `needs_citation`.
- Share of traps called false.
- Missing-finding count.
- Tokens and $ from `usage`.

Run each config several times, because verdicts vary between runs at the same
settings.
